Les 4 axes de qualité — ce que mesure chaque indicateur

Chaque perturbation est notée /100 sur ces 4 axes (le score global est leur moyenne). Critères dérivés des Prescriptions IVC d'Île-de-France Mobilités.
Complétude
Le message contient-il les blocs de caractérisation prescrits : titre + corps, cause/motif, temporalité (période, horaire, reprise), nature (perturbation/interruption/déviation) et localisation (arrêt, gare, direction).
Lisibilité
Principe d'efficacité : longueur adéquate (ni tronqué ni verbeux), titre non générique, phrases rédigées, pas d'excès de MAJUSCULES, indice de lisibilité français.
Hygiène
Propreté technique du texte : pas de balise HTML résiduelle dans un canal texte, pas de placeholder non substitué, pas de mojibake/entités, pas de répétition interne de la même info.
Informativité
Qualité de la conséquence et du service voyageur : conséquence caractérisée (déviation, interruption, arrêt non desservi…), portée précisée (direction, tronçon, « Prévoir 2 bus sur 3 »), formule de politesse conclusive, renvoi/alternative.

🧭 Cohérence de construction des IT par ligne — homogénéité de structure

Mesure si les IT d'une même ligne suivent la même construction, indépendamment des mots. On résume chaque IT par les 9 blocs prescrits présents (titre+corps, cause, temporalité, objet, localisation, conséquence, portée, politesse, renvoi), puis on regarde, entre chaque paire d'IT, sur quel % de ces blocs elles s'accordent (présents/absents pareil). 100 % = même squelette de construction ; plus bas = constructions divergentes. Ne pénalise pas le vocabulaire propre à chaque incident (gares, dates…) — deux IT uniques mais bâties pareil sont cohérentes. Seules les lignes avec ≥ 3 IT.
Lecture : ≥ 85 % très homogène 70–85 % homogène < 70 % construction variable

🔍 Rechercher les IT d'une ligne de bus

Tape le code usager (ex : « 1225 », « 5333 », « 30-05 ») ou le code commercial Navitia (ex : « C00275 »). Toutes ses info trafic s'affichent avec leur score et leurs conseils, et les indicateurs du haut se recalculent sur la sélection.
Seules les IT rattachées à une ligne sont cherchables ici ; les perturbations au niveau arrêt (arrêt non desservi…) restent visibles dans « Détail réseau » ci-dessous.

À noter sur la méthode
  • Un même incident diffusé sur plusieurs canaux (titre, web, SMS, e-mail) avec un texte identique n'enlève aucun point : les prescriptions demandent au contraire un message cohérent et identique sur tous les supports.
  • Deux périmètres : onglet Ferré (RER / Transilien / métro / tram, analysé par ligne) et onglet Bus (5 réseaux, analysé par réseau). Les ICV ascenseurs sont exclues (générées automatiquement par un bot, uniformes, non affichées sur les fronts IT).
  • Les prescriptions imposent de chiffrer la conséquence (« Prévoir 1 train sur 2 ») ; l'axe Informativité valorise ce chiffrage.
  • Le flux line_reports ne contient pas le « transporteur » : il est reconstitué en croisant chaque ligne avec le référentiel Navitia.
  • Recherche par ligne de bus : les IT au niveau arrêt (« arrêt non desservi ») ne portent pas de ligne dans le flux, mais leur numéro figure dans le titre (« Bus 368 : … ») — on les rattache automatiquement à la ligne du réseau (marquées « † rattachée via le titre »), ce qui les rend cherchables. Reliquat non rattaché : annonces au niveau réseau/gare sans numéro de ligne.
